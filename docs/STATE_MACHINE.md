VALIDATING
→ NEEDS_REVIEW
→ VALIDATING

RESOURCE_CHECK
→ BLOCKED_BY_RESOURCE
→ RESOLVING
→ RESOURCE_CHECK

PENDING_APPROVAL
→ REJECTED
→ CLOSED / REWORK

IN_PROGRESS
→ BLOCKED
→ EXCEPTION
→ REASSIGNMENT_PLANNING
→ IN_PROGRESS

→ FAILED
→ IN_PROGRESS

CUSTOMER_APPROVAL
→ REJECTED
→ IN_PROGRESS
